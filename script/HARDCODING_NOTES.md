# Input configuration

Cell types, PEER factors, training population and the TWAS model set are explicit
command-line parameters. No tissue names or tissue-specific presets are used.
Sample-ID matching defaults to exact, and gene annotations default to standard.

The optional historical SLE GWAS profiles retain their accession-specific
formats and known statistical errors solely for explicit reproduction. The
standard GWAS manifest specifies each study schema without tissue inference.
