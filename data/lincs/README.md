## LINCS parse gmt files for mouse and human

We adopted LINCS database with L1000 phase 1 and phase 2 datasets.

There are five files included in this directory:
1. GSE92742_Broad_LINCS_pert_info.txt.gz: Perturbation annotation from L1000 phase 1;
2. GSE70138_Broad_LINCS_pert_info_2017-03-06.txt.gz: Perturbation annotation from L1000 phase 2;
3. LINCS_PRL_top250.gmt: gmt file for LINCS on corresponding mouse genes;
4. LINCS_PRL_top250_human.gmt: gmt for LINCS on human genes, which was converted from house gmt files.
5. LINCS_20260917.R: Examples for TWAS genes computation with our LINCS res.
