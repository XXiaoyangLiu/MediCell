# MediCell Reference Databases (`data/ref/`)

Place external reference databases distributed in the `medicell-ref-data.tar.gz`
release archive under this directory (`MediCell/data/ref/`):

```bash
tar xzf medicell-ref-data.tar.gz -C /path/to/MediCell/data
```

Expected contents after extraction:

- `data/ref/lincs/`:
  - `LINCS_PRL_top250_human.gmt`
  - `LINCS_PRL_top250.gmt`
  - `GSE92742_Broad_LINCS_pert_info.txt.gz`
  - `GSE70138_Broad_LINCS_pert_info_2017-03-06.txt.gz`
